# Recaptured development evidence

The report uses these genuine VSCode screenshots after the user noticed the
computer-control pointer in the original captures. The pointer was moved
outside the captured application window by opening and dismissing a native
menu before each screenshot. No cursor, text, result, identity, or code was
painted out or generated. The document trims unused outer chrome and scales
the original PNGs; the saved PNG files remain unmodified.

Prompt/response images are current views of the saved development conversation.
Source images are current VSCode views of unchanged exports from the actual
commit for each task. `source-versions.json` records original paths, full commit
identities and SHA256 hashes. The export directory names identify the real
student ID, task and commit; they do not alter the source contents.

The original fourteen captures remain one directory above this folder.
These replacement views are not presented as screenshots taken at the time of
the original implementation. Source control status and file counts reflect
the later capture time. Application source, recorded execution results and
exact prompts were not changed during this presentation cleanup.
