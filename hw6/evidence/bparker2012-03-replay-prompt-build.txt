Build a small Python 3.13 Flask application named Secure Notes inside hw6.
Use app.py with a create_app factory, Jinja templates, local CSS, and SQLite.
Implement registration, login, logout, and create/read/edit/delete private notes.
Use a clean, readable interface with a sidebar, note list, editor, clear errors,

Keep the app usable without external APIs, JavaScript, or internet services.
Treat every form field, URL, and cookie as adversarial. Use Werkzeug scrypt
password hashing, parameterized SQL, owner-scoped queries on every note route,

random signing key outside Git, HttpOnly/SameSite cookies, no-cache responses,
security headers, trusted loopback hosts, and debug mode off. Add a bounded
SQLite-backed login/registration rate limit. Store only an opaque session token

Document that note content is plaintext at rest, local HTTP is a classroom mode,
and this is not a production deployment. Pin dependencies with pyproject.toml
and uv.lock, and ignore databases, signing keys, virtual environments, and caches.
