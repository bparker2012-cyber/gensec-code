In this homework, you will utilize any coding agent (Aider, AntiGravity, Codex, Cursor, Claude Code, Copilot, OpenCode) to produce a secure application of your choice from only prompts. You will have to identify the agent selected. The goal of the exercise is to get practice producing a functional Python application using as little effort as possible via a coding agent. Some example applications include generating:

  • Code for an entire LLM application
  • A Python web application for querying a RAG application drawn from security sources
  • An OAuth-enabled web application
  • A network traffic analyzer and visualizer
  • A web-based steganography tool
  • A re-implementation of functions found in common security tools such as nmap, hydra, wfuzz, commix, or xsstrike.
  • A web site or code fuzzer for testing web sites or programs for errors
  • A macro for an Excel spreadsheet that runs an executable when opened that exfiltrates data on a machine
  • A DLL that launches cmd.exe when loaded using RunDLL to create a backdoor

As the application is developed, keep track of the main prompts utilized to generate the code of your application in file prompts.txt, in order to replay its recreation for your screencast. Take screenshots of the prompts and the agent's replies, and copy them to the Homework Word document. Upon completion of the application, push the resulting code and prompts file to your repository before class.

Upon completing your application, you will replay the development and demonstration of your application from scratch using the prompts in prompt.txt via a narrated screencast of no longer than 5 minutes. Ensure that the video camera is turned on initially in your screencast. The screencast should follow the order given below:

  • Check out the homework from your course repository using git clone.
  • Perform an overview walk-through of the prompts in prompts.txt.
  • Perform a replay of the prompts in prompts.txt to generate your application.
  • Cover the security aspects of your application.
  • Demonstrate the application produced showing its capabilities as well as its limitations.

Upload your screencast video file to your Youtube account. Ensure that it is unlisted and that the video URL is accessible without an account. Use your browser in incognito mode to check the video URL. Add the recording URL to the homework PDF file. Push the changes that include the updated URL to your repository before class.

Follow these instructions to submit your homework:

  1. Ensure the latest homework code is pushed to your course repository on Github.
  2. Enter your repository URL on the provided field in the homework Word document.
  3. Enter the screencast URL on the provided field in the homework Word document.
  4. Copy screenhsots with all prompts and the agent's replies to the homework Word document.

  6. Upload the PDF to the Homework Canvas page before the deadline.
